F-01 자세히

요약

조작된 이미지 헤더의 width 값이 32비트 곱셈에서 넘쳐 행 버퍼가 실제보다 작게 할당되고, 이어지는 memcpy()가 힙 경계를 넘어 씁니다.

경로: 진입fuzz_entry() → decode_image() → parse_header() → read_chunk() → copy_rows() → memcpy()싱크

근본 원인 src/rows.c 205–214행 · 샘플 코드

  1. 207행 · 원인32비트 곱셈이 넘쳐 4바이트 버퍼만 할당됩니다.
  2. 212행 · 싱크64비트로 다시 계산한 길이만큼 복사해 힙 경계를 넘어 씁니다.
