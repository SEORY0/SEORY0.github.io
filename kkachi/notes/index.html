04 — Notes / 연구 노트

연구 노트

KKACHI를 만들며 배운 것을 짧은 노트로 정리하고 있습니다. 첫 노트는 연구 프리뷰와 함께 공개합니다.

04.1Drafts / 준비 중

준비 중인 노트 세 편

아직 공개된 노트는 없습니다. 노트마다 붙인 그림은 노트 주제를 나타낸 설명용 도식으로, 화면에 들어오면 한 번 그려집니다.

  1. N-01준비 중 · Draft

    가설을 버리는 기술: 기각 기록이 발견을 빠르게 만드는 이유

    FIG. N-01

    가설이 가지처럼 자라다 끊깁니다. 끊은 자리는 기록으로 남고, 줄기는 발견까지 나아갑니다.

    KEY · 누르면 그림에서 그 부분을 짚어 보여 줍니다

  2. N-02준비 중 · Draft

    재현 3/3의 의미: 격리 환경, 고정 시드, 새 VM

    RUN 1 RUN 2 RUN 3 3/3

    FIG. N-02

    격리된 새 환경에서 고정된 입력으로 세 번 재현합니다. 한 번이라도 어긋나면 발견이 아닙니다.

    KEY · 누르면 그림에서 그 부분을 짚어 보여 줍니다

  3. N-03준비 중 · Draft

    호출 그래프는 지도일 뿐: 추적이 멈추는 지점 기록하기

    ENTRY STOP

    FIG. N-03

    추적이 호출 그래프를 따라가다 멈춥니다. 어디까지 따라갔는지, 멈춘 지점에 표시를 남깁니다.

    KEY · 누르면 그림에서 그 부분을 짚어 보여 줍니다
