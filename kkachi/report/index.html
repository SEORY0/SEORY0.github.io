copy_rows()의 행 길이 계산에서 정수 오버플로

Target

01 요약 Summary

조작된 이미지 헤더의 width 값이 32비트 곱셈에서 넘쳐 행 버퍼가 실제보다 작게 할당되고, 이어지는 memcpy()가 힙 경계를 넘어 씁니다.

Rule보고서 작성 규칙 01

첫 문단은 한 문장으로 끝납니다. 무엇이, 어디서, 왜.

02 영향 Impact

조작된 이미지 한 장으로 힙 버퍼 뒤쪽 메모리를 덮어쓸 수 있습니다. (추정 · 검토 필요)

Rule보고서 작성 규칙 02

추정은 추정이라고 씁니다. 확인된 사실과 섞지 않습니다.

03 근본 원인 Root cause

src/rows.c:207 stride를 32비트로 계산 →src/rows.c:212 64비트로 다시 계산한 길이만큼 복사.

Rule보고서 작성 규칙 03

모든 주장에는 코드 위치가 붙습니다.

04 재현 Reproduce

$ ./repro --seed 7f2a poc-f01.img
ASan: heap-buffer-overflow · rows.c:212

격리 VM에서 3회 모두 같은 위치에서 중단됩니다.

Rule보고서 작성 규칙 04

재현 절차는 복사해서 그대로 실행할 수 있어야 합니다.
