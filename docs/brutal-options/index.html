A

Swiss CV

라벨은 왼쪽 좁은 모노 열, 내용은 오른쪽. 괘선은 전부 풀 콘트라스트이고 섹션 시작선만 2px로 굵습니다. 가장 "이력서"답고, 정보 밀도가 높을수록 더 예뻐지는 구조입니다.

Type
Pretendard 15px 본문 · IBM Plex Mono 11px 메타
Scale
h1 7.5vw · h2 11px 대문자 · h3 15px
Rules
2px 섹션 · 1px 행 · 2px 좌측 들여쓰기
Hover
행 전체 반전 (배경 ↔ 글자)
Risk
좁은 화면에서 2열이 1열로 접힘
B

Terminal

전부 모노스페이스. 행 번호는 CSS 카운터, 섹션은 라벨이 윗선에 박힌 박스. 가장 "보안 연구자"다운 결이고 CSS도 가장 짧게 끝납니다. 한글은 Pretendard로 자동 폴백됩니다.

Type
IBM Plex Mono 13.5px 단일 · 한글 Pretendard 폴백
Scale
h1 6.5vw · h2 11px 대문자 · 본문과 h3 동일
Rules
1px 박스 · 1px 점선 행 · 번호 열 44px
Hover
행 전체 반전 · 링크는 [ ] 괄호
Risk
한글 본문이 많아지면 모노·산세리프가 섞여 보임
C

Poster

서체 하나, 모노 없음. 이름과 섹션 제목을 거대하게 키우고 본문은 작게 두어 크기 대비만으로 위계를 만듭니다. 가장 "그래픽"적이고 스크롤할 때 리듬이 생깁니다.

Type
Pretendard 단일 · 15px 본문 · 17px 소개
Scale
h1 19.6vw · h2 6.4vw 대문자 · h3 18px
Rules
1px 전체 · 3px 좌측 들여쓰기
Hover
제목 3px 밑줄 (반전 없음)
Risk
세로로 길어짐 · 긴 섹션명은 줄바꿈 필요
