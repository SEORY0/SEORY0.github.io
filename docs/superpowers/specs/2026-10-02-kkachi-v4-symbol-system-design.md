## 1. 기본 결정 (리서치 권고 채택. 사용자가 반대하면 바꾼다)
- **◆ 마름모를 없앤다.** '확인·발견' 표지는 회전하지 않는 **주장 판**(3:2 판) 문법으로 바꾼다.
  - 회전한 사각형은 쓰지 않는다. 홈 A 타일의 마름모 노드도 정사각 노드로 바꾼다.
  - 웨이트리스트 헤드라인 끝의 ◆도 없앤다.
- **×를 쓰지 않는다**(회전한 +로 읽힌다). 닫기는 "닫기" 글자와 Esc로 하고, 기각은 사선 한 줄(/)로 표시한다.
- **심각도**: 에이전트가 제안하면 점선 막대로, 사람이 확정하면 채운 막대와 사람 표지로 그린다. 확정 전에는 '검토 전'이다. CVSS는 사람이 확정한 경우에만 보인다.
- **상태 낱말**: '재현 확인'(에이전트, 3/3)과 '승인'(사람)을 구분한다. v3의 '확인'은 '재현 확인'으로 바꾼다.
- **밝은 테마의 자개**: 자개 심볼은 늘 자기 옻칠 바탕을 갖는다. 흰 면에 바로 깔지 않는다.
- **샘플 수치**: 깔때기와 수치는 세션 7F2A의 실제 샘플 숫자만 쓴다(함수 1,284 → 가설 4 → 기각 2·보류 1 → 재현 3/3 → 발견 1).
  - 개요의 다른 데모 세션은 계속 "데모용 가상 세션"으로 표시한다.
- **연구 노트**: 내비에 그대로 둔다. 다만 세 노트가 '준비 중'이라는 사실과 각 노트가 다룰 내용을 한 줄로 분명히 쓴다.

## 2. 디자인 시스템 v4 (리서치 §5–§7을 구현한다)
- **심볼 라이브러리**
  - 파일: `assets/kkachi/symbols.svg`(SVG `<symbol>` 스프라이트). 16px 격자, 선 1.25px, square cap, 회전 없음.
  - 리서치 §5의 기본 모양을 담는다: 판(주장), 정사각(코드 위치), 상사(통과 한 번), 고리(사람), 겹선(경계), 문서(보고서), 삼각(시스템 실패).
  - 상태 변형도 함께 둔다(후보, 검증 중, 추적됨, 재현 k/3, 재현 확인, 승인, 보류, 기각, 사람 차례/결정, 실패).
  - 심각도 막대 사다리와 세션 라인 조각을 둔다.
  - 16px과 32px에서 알아볼 수 있어야 한다. 늘 낱말과 함께 쓴다(사이트는 라벨이 항상 보이고, 대시보드는 라벨 또는 툴팁+스크린리더 이름).
- **선 토큰**
  - 리서치 §6의 굵기 사다리를 쓴다: `--lw-0..3`, `--lw-state`, `--lw-focus`. dash 토큰도 쓴다: cand, claim, seg, cut-gap, double-gap.
  - 한 화면에서 굵기 3개와 결 3개를 넘지 않는다.
  - 화살촉 대신 가늘어지는 간선을 쓰고, 끝 표지는 끝에만 둔다(모로단청).
- **색: lights-out**
  - 평소에는 회색 옻칠이다.
  - violet은 재현 확인과 승인에, 자개는 입증된 것에만 쓴다.
  - 경고·실패 색은 사람의 행동이 필요할 때만 켠다.
  - 장식 violet과 장식 자개는 없앤다.
- **자개 규칙**(리서치 §7)
  - 자개는 '입증됨' 하나만 뜻한다.
  - 데이터 UI에서는 두 형태로만 쓴다: 재현 확인 3/3의 세 조각, 승인된 발견의 판 내부. 선택된 발견의 확인 경로에는 끊음질 조각 선을 쓴다.
  - 셰이더는 한 화면에 하나다(큰 인장 32px 이상이거나 확인 전환 순간). 작은 심볼은 정적 타일을 패턴으로 쓴다.
  - 2/3은 자개가 아니다. 세 번째 통과 때 세 조각이 함께 자개로 바뀐다(약 240ms, 동작 줄이기에서는 즉시).
- **컴포넌트**(신규·개편): 세션 라인, 깔때기 선, 판정 줄(심각도·검증·상태·다음 행동 네 칸), 증거 행, 사람 검토 상자(겹선으로 분리, 버튼마다 결과 설명), 재현 카드 세 장, 가설 차선 타임라인, 관문 원장(세로 등뼈), 신원 띠(무엇·누가·언제·어디서), 갱신 기록, 자율성 띠(읽기 ✓ · 격리 실행 ✓ · 외부 전송 안 함 · 공개는 사람), 신뢰 바(다섯 원칙 심볼), 입력→출력 심볼 띠, 정성 비교 매트릭스(채운 정사각, 반, 빈 정사각. 원은 사람 전용).
- **스타일 가이드** `/kkachi/system/`를 v4로 갱신한다. 심볼 전체(두 테마, 16/32px), 선 문법, 자개 규칙, 새 컴포넌트, 쓰는 법과 쓰지 말 것을 보여 준다.

## 3. 사이트 전달력 (리서치 §8)
첫 화면에서 다섯 가지가 바로 보여야 한다: **누구**(기업 보안팀) · **무엇**(소스와 바이너리를 읽고 재현으로 입증된 취약점만 보고하는 자율 연구 에이전트) · **왜**(확인되지 않은 경고가 검토 시간을 먹는다) · **증거**(세션 라인: 1,284 → 4 → 기각 2·보류 1 → 3/3 → F-01, 샘플 데이터) · **다음**(대기자 명단).

- **홈**
  - 메시지 타일 2×2: 워드마크, 헤드라인, 한 줄 정의(누구·무엇), CTA는 390px에서 한 줄이어야 한다.
  - 세션 라인 타일(가로로 넓게, 라벨 표시)을 둔다. 글자 아트는 4–6개로 줄인다.
  - 이동 버튼은 그대로 둔다(왜 KKACHI인가, 연구 노트, 대기자 명단).
  - 금문 전환, 동작 줄이기, 일시정지 규칙도 그대로 둔다.
- **why**
  - 히어로 바로 아래에 다음을 차례로 둔다:
    - 세션 라인 컴포넌트.
    - 입력→출력 심볼 띠: 승인 범위, 소스, 바이너리, 빌드 설정, 크래시 로그(선택) → ㄲ → 발견 판, 재현 명령, 수정 방향, 기각 기록.
    - 실행 위치: 고객 환경 또는 KKACHI 격리 환경.
    - 신뢰 바(다섯 원칙).
  - '왜 필요한가'는 정성 비교 매트릭스로 보여 준다: 정적 분석 / 퍼저 / KKACHI × 의심 지점 / 입력에서 도달 / 재현 / 원인과 수정 / 버린 가설 기록. 통계는 쓰지 않는다.
  - 작동 원리는 관문 원장 심볼과 출력 칩으로 보여 준다. 판단의 기록(그래프, 가설 차선)과 보고서 발췌는 증거 행 형식으로 둔다.
  - 문장은 장면마다 1–2줄이고, 나머지는 심볼·선·숫자와 툴팁에 맡긴다.
  - 샘플 표시는 '샘플 데이터' 칩 하나와 겹선 영역으로 한다. 점선 테두리는 '미확인'의 뜻이므로 샘플 표시에 쓰지 않는다.
- **waitlist**
  - 브랜드 재질 설명을 '받는 것 / 드리는 정보'로 바꾼다. 받는 것은 기존 사실만 쓴다: 공개 일정 소식, 첫 연구 노트, 연구 프리뷰 초대. 나머지는 쓰지 않는다.
  - 흑칠, 끊음질, 자개 설명은 `/kkachi/system/`으로 옮긴다. 깃털 그림은 줄인다.
  - 폼은 여전히 아무것도 전송·저장하지 않는다.
- **notes**: ⊣ = 기각, 점선 꼬리 = 보류로 의미를 통일한다. 세 노트 그림은 시스템 설명 그림으로 승격하고, 각 노트에 한 줄 요약을 단다.
- **390px 문제**: 홈 CTA가 두 줄로 접히는 문제를 고친다. why 콘솔은 처음부터 최종 상태로 보여 준다.

## 4. 대시보드 (리서치 §9)
- **주소**(정적 여러 페이지, 공용 셸)
  - `/kkachi/dashboard/`: 개요("사람 차례")와 발견 목록.
  - `/kkachi/dashboard/finding/`: 발견 F-01 상세.
  - `/kkachi/dashboard/session/`: 세션 7F2A 상세.
  - 모두 noindex이고, 사이트맵에서 빠지며, 사이트에서 링크하지 않는다.
- **공용 데이터**: `assets/kkachi/dash-data.js`(ES 모듈) 한 곳에 샘플 데이터를 둔다. 7F2A는 프로토타입 사실이고, 데모 세션은 '데모용 가상'으로 표시한다. 세 화면이 같은 수치를 쓴다.
- **셸**
  - 왼쪽 내비: 워드마크, 개요, 발견, 세션, 대상, 기록, 설정. 샘플에 없는 화면은 비활성으로 두고 "샘플에 없음"이라고 쓴다.
  - 위쪽 바: 검색(/), 시간 제어(실시간 또는 기록, KST), 에이전트 상태 캡슐, 자율성 띠, '샘플 데이터' 칩, 테마 토글.
- **개요**
  - 세 질문 타일(실행 중, 재현 확인, 사람 차례)은 필터 역할도 한다.
  - 검토 대기열을 주 위젯으로 둔다.
  - 줄어드는 깔때기를 두고, 빠지는 곳마다 이유를 단다.
  - 세션 표에는 세션 라인 열, 절대 시작 시각, 0이 들어간 탭, 사건 밀도 띠, 신선도 표시를 둔다.
  - 접힌 '방법과 한계' 패널을 둔다.
  - 6줄 심각도 막대그래프 대신 한 줄 심각도 심볼 띠를 쓴다.
- **발견 목록**: 필터 레일(0개 버킷 포함). 행은 판 상태 · 심각도 · 주장 문장 · file:line · CWE 사슬 · 재현 · 검토 순이다.
- **발견 상세(F-01)**
  - 신원 띠, 판정 줄 네 칸, 증거 행.
  - 탭: 요약 / 경로(그래프와 번호 단계 쌍둥이) / 가설(버린 것 포함 트리) / 재현(카드 세 장, 복사할 수 있는 명령, 패치 후 재실행) / 기록(감사 기록, 원본은 마지막에).
  - '에이전트가 한 것 / 하지 않은 것(사람 몫)' 행.
  - 겹선으로 분리한 사람 검토 상자(버튼마다 결과 설명), 갱신 기록, 스크롤하면 붙는 간단한 머리.
- **세션 상세(7F2A)**: 신원 띠(절대 시각), 관문 원장, 가설 차선 타임라인, 그래프(조사할 수 있음), 유형별 세션 기록과 개수 필터, 재생(커서와 머리 상태 동기화).
- **공통**
  - 키보드: / ↑↓ Enter Esc ←→ Space ?.
  - 그래프마다 표 쌍둥이를 둔다.
  - 상태: 2단계 로딩(같은 모양의 스켈레톤, 스피너 대신 관문 진행), 낙관적 빈 상태(기각 이유와 "기각은 안전을 뜻하지 않습니다"), 첫 실행 3단계 안내, 패널별 오류(삼각 + 다시 시도), '판정 없음' / '기록 없음' / '일부 경로만 표시 · +N'.
  - 두 테마 모두 AA. 반응형은 1280 이상이 밀도 높은 화면, 768은 레일 내비, 390은 단일 열이다.
