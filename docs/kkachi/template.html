지키는 것

  • 허가받은 대상만 봅니다.소유자나 권한자가 승인한 범위 안에서만 분석하고 실행합니다.
  • 격리된 곳에서만 재현합니다.재현은 매번 새로 만든 일회용 샌드박스 안에서 실행합니다.
  • 재현되지 않으면 발견이 아닙니다.추측은 가설로 남기고, 보고서에는 쓰지 않습니다.
  • 버린 가설도 기록합니다.무엇을 왜 버렸는지가 다음 연구를 빠르게 만듭니다. 틀린 길을 아는 것도 증거입니다.
  • 혼자 공개하지 않습니다.보고서는 사람의 검토를 거친 뒤에만 밖으로 나갑니다. 제보 채널과 공개 시점은 사람이 정합니다.
