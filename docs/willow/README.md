# Willow

The home willow is `trauerweide-skizze-2021-cc0.jpg` ("Trauerweide Skizze 2021",
Wikimedia Commons, CC0) turned into text:

    python willow_ascii.py trauerweide-skizze-2021-cc0.jpg 44 130 20 800 720 0.7 short

Needs Pillow. Paste the output into the `.willow` <pre> in `_layouts/home.html`.
