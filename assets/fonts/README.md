# Font sources

Existing site typefaces, served locally to avoid third-party font requests.

- Pretendard Variable 1.3.9: https://github.com/orioncactus/pretendard/tree/v1.3.9 (original dynamic Unicode subsets; all language coverage retained).
- IBM Plex Mono: https://github.com/google/fonts/tree/main/ofl/ibmplexmono (Google Fonts v20 WOFF2 Unicode subsets, normal 400 and 700; loaded on posts only).

Original SIL Open Font License files are included in each directory. Original fallback font binaries and Unicode coverage are preserved. CSS uses the Portfolio Sans alias for the compatible primary subset and fallback faces; see portfolio-sans/README.md. Font display remains swap.
