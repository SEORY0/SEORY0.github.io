# Portfolio Sans web subset

A character subset of Pretendard Variable 1.3.9, renamed PortfolioSans in font naming records to respect the original Reserved Font Name. Glyph outlines and variable weights are unchanged. Original copyright and OFL are retained.

Source: https://cdn.jsdelivr.net/gh/orioncactus/pretendard@v1.3.9/packages/pretendard/dist/web/variable/woff2/PretendardVariable.woff2
Source SHA256: 9599f12fd42fc0bce1cd50b47a0c022e108d7aa64dd0d1bb0ed44f3282d900b4
FontTools 4.57.0; all layout features and naming metadata retained. Character list: characters.txt (651 characters).

The site loads this subset first. The complete original Pretendard Unicode subsets remain as fallback, so future text outside this subset still renders correctly without a rebuild step. Regenerating the subset is optional when content expands.

Both stylesheets use the Portfolio Sans CSS alias. The primary subset is declared last with explicit Unicode ranges; other characters select the original fallback subsets without downloading duplicate fonts for the same text.
